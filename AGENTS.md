# Working on this project

This app targets **Expo SDK 54**, not the latest. Read the versioned docs at
https://docs.expo.dev/versions/v54.0.0/ before writing code.

The SDK version is pinned deliberately — see PROJECT_STATE.md ("Decisions worth
knowing") before upgrading it.

Start by reading **PROJECT_STATE.md**. It covers current status, the reasoning
behind non-obvious choices, and what's still outstanding.
